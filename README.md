# Nokia 3310 Snake Game 🐍📱

A classic Nokia 3310-style Snake Game built using Python and Pygame.

## Features

- 🎮 Classic Snake gameplay
- 📱 Nokia 3310-inspired retro design
- 🟢 Monochrome LCD-style screen
- 🔢 Nokia-style keypad interface
- ⬆️⬇️⬅️➡️ Arrow key controls
- 🔢 2, 4, 6, 8 keypad controls
- 🍎 Random food generation
- 🏆 Score tracking
- 💥 Collision detection
- 📈 Increasing game difficulty
- 🔄 Restart after Game Over

## Technologies Used

- Python
- Pygame
- Random
- Sys

## Controls

| Key | Action |
|---|---|
| 2 / ↑ | Move Up |
| 8 / ↓ | Move Down |
| 4 / ← | Move Left |
| 6 / → | Move Right |
| 5 / Enter / Space | Restart |
